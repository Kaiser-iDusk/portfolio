Gemini Integrated C Shell
Developed a Shell utility for Unix like systems in C with built-in Gemini support for command suggestions.
  • Implemented most commonly used functions like cd, ls, pwd, pipe, redirects, background and command chaining.
  • A tokenizer parses the input and executes the command from left to right except for cases where background task is used.
  • Gemini client is invoked using ']' and the user writes the query in natural english. Then the Gemini API is invoked with CURL and the execution context and the prompt is sent as payload.
