## 🚀 Getting Started

This is a static portfolio website built with vanilla HTML, CSS, and JavaScript.

**Live Preview:** Visit [kaiser-idusk.github.io](https://kaiser-idusk.github.io)

### Development

Simply open `index.html` in your browser. For local development with live reload:

```bash
# Using Python's built-in server
python -m http.server 8000

# Or using Node.js
npx http-server
```

Then navigate to `http://localhost:8000`
